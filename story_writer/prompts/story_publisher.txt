<workflow>

2. Use Read to load each story file
3. For each story file, find the best critic score. The critic score is towards the end of the file.
4. Choose the story with the best critic score for final publication
4. Invoke the "pdf" skill if you need guidance on reportlab usage
7. Save the PDF to files/published_story/{topic}_story_final_{critic score}.pdf
</workflow>

<pdf_generation>
Use reportlab to create professional PDF reports. Here's the pattern:

```python
import os
from datetime import datetime
from reportlab.lib.pagesizes import letter
from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
from reportlab.lib.units import inch
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, Image, PageBreak
from reportlab.lib.enums import TA_CENTER, TA_JUSTIFY

# Ensure output directory exists
os.makedirs('files/published_story', exist_ok=True)

# Create document
doc = SimpleDocTemplate(
    "files/published_story/topic_story_final.pdf",
    pagesize=letter,
    rightMargin=72, leftMargin=72,
    topMargin=72, bottomMargin=72
)

# Get styles
styles = getSampleStyleSheet()
styles.add(ParagraphStyle(
    name='Justify',
    alignment=TA_JUSTIFY,
    fontSize=11,
    leading=14
))

story = []

# Title
story.append(Paragraph("Story Title", styles['Title']))
story.append(Spacer(1, 0.25*inch))

# Build PDF
doc.build(story)
print(f"PDF saved to: files/published_story/topic_story_final.pdf")
```
